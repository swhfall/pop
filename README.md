## FASTA reader
Библиотека для работы последовательностями и файлами формата Fasta
## Установка и запуск
1. Клонируйте репозиторий
   git clone https://github.com/swhfall/pop
2. Перейдите в папку проекта:
   cd fasta_reader
3. Запустите демо-версию:
   python main.py
## Описание классов
# Класс Seq
Работа с биологическими последовательностями
Определение алфавита
Хранение заголовка и последовательности
# Класс FastaReader
Чтение Fasta фвйлов
Проверка формата файла
